# 🎹 Kharla Piano PWA - Landing Page

Bienvenido al repositorio de la **Landing Page oficial de Kharla Piano PWA**. Este sitio web presenta el sintetizador y piano virtual, destacando sus características técnicas, tecnologías utilizadas y ofreciendo una vía directa para probar la aplicación o apoyar su desarrollo.

🔗 **[Ver Landing Page en Vivo](https://ciromellado.github.io/Kharla-Piano-PWA--Ciro/)**  
🎹 **[Probar la Aplicación del Piano](https://ciromellado.github.io/Kharla-Piano-PWA--Ciro/)** *(Ajusta esta URL si mueves la app a una subcarpeta)*

---

## ✨ Características de la Landing Page

- **Diseño Elegante y Responsivo**: Fondo beige claro (`#F9F7F2`) con acentos en rojo profesional, optimizado para móviles, tablets y escritorio.
- **Sección de Héroe con Imagen**: Espacio dedicado para mostrar una captura de pantalla o arte promocional del sintetizador.
- **Tarjetas de Características**: Presentación visual clara del Motor de Audio Web, Soporte MIDI, Efectos DSP, y más.
- **Sección de Tecnologías**: Muestra transparente del stack técnico (HTML5, CSS3, JS, Web Audio API, Web MIDI API).
- **Integración de Donaciones**: Botón destacado y seguro que dirige a PayPal para apoyar el desarrollo continuo del proyecto.
