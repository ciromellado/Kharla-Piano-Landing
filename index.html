✨ Características Principales

🎛️ Motor de Audio Web

Generación de sonido en tiempo real con múltiples osciladores (seno, sierra, triángulo) y envolventes personalizadas mediante Web Audio API.

🎹 Piano Sampler

Compatible con librerías externas como Splendid Grand Piano para lograr un sonido acústico realista de alta fidelidad.

🎚️ Nord Synth Pad

Módulo de pads analógicos integrado con selector de tipos de sonido (Warm Pad, Soft Strings, Analog Sweep) y control de volumen independiente.

✨ Efectos DSP Avanzados

Chorus modulado con LFO, Delay con control de tiempo y feedback, y una reverb convolucional envolvente para un sonido profesional.

🎵 Reconocimiento de Acordes

Detecta automáticamente las notas presionadas en tiempo real y muestra el nombre del acorde en la pantalla.

🔌 Conectividad MIDI

Soporte completo para conectar teclados y controladores MIDI físicos vía USB/Web MIDI API (tanto entrada como salida) de manera muy fácil e inmediata.

📱 Diseño Responsivo

Interfaz optimizada para computadoras y tablets, con un diseño elegante inspirado en hardware profesional sobre un fondo beige claro.

🚀 Tecnologías Utilizadas

Construido con herramientas modernas para un rendimiento óptimo y una experiencia de desarrollo robusta.

Web MIDI API
